# Helix · Seed 模板库

> 触发：结晶 Seed 时按任务类型取用，把"想清楚八个栏目"降为"填空 + 删不适用项"。
> 模板是起点不是免检：填完仍要过歧义门；`<>` 占位必须填实，填不出说明该维度还没澄清。

## bugfix

```markdown
# Seed: 修复 <bug 一句话>
## Goal          <症状> 在 <复现条件> 下不再出现，且根因被声明并修复
## Non-goals     顺手重构；修复无关警告；改进相邻功能
## Constraints   不改公开接口/行为契约；修复面尽量小
## Acceptance Criteria
- [ ] AC1: 原复现步骤转绿 — 验证: <复现命令/步骤>
- [ ] AC2: 根因已声明（一句话+证据位置）— 验证: 收据里有"根因是 X，证据是 Y"
- [ ] AC3: 相邻场景回归通过 — 验证: <相关测试命令>
- [ ] AC4(时序/并发类): 重复运行 20 次全绿 — 验证: <循环运行命令>
## Ontology      <出错路径涉及的实体与状态流转>
## Stop conditions  done=AC 全过；blocked=无法复现且无法构造观测
```

## feature

```markdown
# Seed: <功能一句话>
## Goal          <用户/调用方> 能 <做什么>，成功的样子是 <可观察结果>
## Non-goals     <这次坚决不做的相邻功能，至少写一条——写不出就是范围没想清>
## Constraints   <不能动的现有契约>；<性能/兼容要求>；跟随项目现有 <命名/错误处理> 惯例
## Acceptance Criteria
- [ ] AC1: 主路径 <输入→期望输出> — 验证: <测试/手动步骤>
- [ ] AC2: 边界 <空输入/越权/超限> 的行为是 <预期> — 验证: <方式>
- [ ] AC3: 失败路径给出 <预期错误形态> — 验证: <方式>
## Ontology      <新实体是什么、状态集合、生命周期；与现有实体的关系>
## Stop conditions  done=AC 全过；scope-exceeded=触碰 Non-goals
```

## refactor

```markdown
# Seed: 重构 <对象>
## Goal          <结构目标：职责归位/去重/降复杂度>，**外部行为不变**
## Non-goals     任何功能变更或"顺手修 bug"（发现 bug 记 later，单独任务修）
## Constraints   公开接口签名不变（或列出获批的变更清单）；测试断言不弱化
## Acceptance Criteria
- [ ] AC1: 全量测试重构前后同绿 — 验证: <测试命令>（重构前先跑一次记录基线）
- [ ] AC2: <结构度量：如 X 的职责移入 Y / 删除重复实现 Z> — 验证: diff 审查
- [ ] AC3: 无残留死代码/旧路径 — 验证: 反熵清退扫描
## Ontology      <重构前后各自的归属图：行为 → owner>
## Stop conditions  done=AC 全过；scope-exceeded=行为发生变化
```

## migration（数据/schema/依赖迁移）

```markdown
# Seed: 迁移 <对象> 从 <旧> 到 <新>
## Goal          <迁移完成的定义，含旧路径的处置>
## Non-goals     迁移窗口内的功能新增
## Constraints   数据零丢失；<可接受的停机/双写窗口>；回滚路径必须存在且演练过
## Acceptance Criteria
- [ ] AC1: 迁移后数据完整性 <校验方式：行数/校验和/抽样比对> — 验证: <命令>
- [ ] AC2: 新路径承载全部流量/调用 — 验证: <方式>
- [ ] AC3: 回滚演练通过 — 验证: <回滚步骤+验证>
- [ ] AC4: 旧路径已删除或带退役触发器 — 验证: 反熵清退记录
## Ontology      <新旧两套实体/格式的映射表；不可映射项的处置>
## Stop conditions  blocked=完整性校验不过；永不静默跳过校验
```

## 用法纪律

- 模板选不准（任务横跨两类）→ 以风险更高的一类为主模板，从另一类抄 AC。
- L1 迷你 Seed 不用模板（3 行足够）；模板服务 L2。
- 每个模板的 AC 是**下限**不是上限：歧义门的 success 维度要求每条 AC 写得出验证动作，模板占位没填实不算过。
