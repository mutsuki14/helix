# Helix · 路由协议（改道 / 插入 / 预算 / 衔接）

> 触发：中途要升降级、长任务被插入新请求、上下文快满、分级拿不准要用 triage、宿主自带计划模式。
> 原则：路由的成本发生在每个任务上，所以协议要薄——本文件只在命中时读。

## triage 确定性分级

大多数任务肉眼可判级，**不要每次都调工具**。只在 L1/L2 之间拿不准、或用户质疑分级时使用：

`node scripts/gate.mjs '{ mode: "triage", cross_module: false, contract_change: false, shared_code: true, cross_session: false, high_risk: false, multi_step: true, ambiguity_guess: 0.2 }'`（脚本在本技能目录下；无 node 时按规则手算并展示判定过程）

七个信号全部必填（强迫逐项过脑）。判定规则（工具内置）：契约变更 / 跨模块 / 跨会话 / 高风险（数据、安全、不可逆）/ 歧义 > 0.4 任一命中 → L2；多步 / 共享代码 / 歧义 > 0.1 → L1；全无 → L0。共享代码永远到不了 L0（红线内置）。

**机械证据**：`shared_code` 拿不准时不要猜——先 grep 涉及文件被引用的位置数（>2 处调用方即共享），拿数字再填。

**误判校准**：校准账本每行可加 `"level_initial":"L1","level_final":"L2"`（初判级别 vs 实际走完的级别），`calibrate` 模式会统计误判率与方向——初判系统性偏低说明红线执行不严。

## 升级协议（干着干着变复杂）

触发：L1 执行中发现契约变更 / 跨模块蔓延 / 歧义爆炸 / 已用 2 圈仍不收敛。

1. **停手**，更新 Route line：`Route 升级: L1 → L2（发现契约变更）`。
2. **补结晶 Seed**：已知信息直接填入；已完成的工作对应的 AC 直接标 pass 并附上已有证据——**升级不重做已完成的活**。
3. 跑一次 Gate 1 确认当前工作区是绿的，再从 `build` 继续；若升级原因是歧义本身 → 回 `clarify` 补访谈。

L0 → L1 更轻：发现要多步或要验证时，补 3 行迷你 Seed、一句话声明，继续。

## 降级协议（澄清后发现其实简单）

触发：L2 的 clarify 完成后发现单模块 + 验收明确 + 无契约变更（歧义门轻松通过且 Seed 很小）。

1. 更新 Route line：`Route 降级: L2 → L1（澄清后确认单模块）`。
2. Seed 缩为迷你 Seed；已创建的 `.helix/` 文件保留作记录，不再更新。
3. 评估收回到机械 + 语义两级；共识门取消。

为仪式而仪式是 Helix 的失败模式——降级和升级同样光荣。连续两圈干净的努力度降档见总路由"努力度阶梯"。

## 插入任务路由（长任务中来了新请求）

先判定新请求与当前 Seed 的关系，三选一：

| 关系 | 判据 | 走法 |
|---|---|---|
| **子任务** | 在当前 Goal 范围内的细化/修正 | 并入当前圈执行，AC 不变 |
| **独立任务** | 范围外，但用户要现在做 | 当前任务在 journal 记挂起点（做到哪、下一步）→ 新任务独立分级独立走（多为 L0/L1）→ 完成后从挂起点恢复。两个任务的 Seed **不混** |
| **scope change** | 要求改变当前的目标/约束/验收 | reseed 协议（`clarify`）：旧 Seed 归档，显式记录差异 |

禁止：把插入请求悄悄揉进当前 Seed"顺手做了"——这是漂移的最大入口，应在路由层就拦住。

## 上下文预算路由（快满时减速）

信号：会话很长、已读大量文件、宿主提示压缩临近。动作按序：

1. **先保状态再干活**：L2 立即把当前圈状态追加进 journal；L1 在下一条回复末尾输出"续航块"（迷你 Seed + 已完成 + 下一步），让对话本身可恢复。
2. **缩小读集**：只读 diff 与直接相关文件；大文件用窗口读；探索改派子代理（子代理上下文是新鲜的，回收结论不回收原文）。
3. **不开新战线**：不开始新的 L2；当前批次收尾优先于开新批次。
4. 压缩后恢复：按 `evolve` 的恢复协议，从 journal/续航块续跑，不重推已验证事实。

## 模型分层建议（宿主支持子代理选模型时）

按任务性质配模型档位，省钱不省判断力；宿主无此能力则忽略本节：

- 只读探索、机械收集、批量 grep → **低档**模型子代理。
- 实现、常规评审 → 会话**同档**。
- 辩论裁决、共识门、根因裁定 → **同档或高档**，永不低档——裁决错误的返工远贵于模型差价。

## 与宿主计划模式的衔接

宿主自带计划/审批设施（如 Claude Code 的 plan mode）且已激活时，**不做双计划**：

- Helix 的计划内容（批次、任务、验证步骤）并入宿主的计划产物；不再另建 `.helix/plan.md`。
- Seed 仍归 Helix：宿主计划通常不承载 Non-goals / AC 验证方式 / 本体，这些留在 Seed 里。
- 批次检查点映射到宿主的审批节点；宿主批准 = 批次放行。
